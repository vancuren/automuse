# Research notes behind PLAN.md

Collected 2026-11-03 by ten parallel researchers, each checked by an independent fact-checker, plus a completeness critic.

- `dossier.md`: per topic, the summary, key claims with sources, the fact-checker's corrections and missed findings, recommendations, risks, and open questions. Topics: Meta model catalog, SAM 3.1, Meta speech models, Baseten and Fireworks, training options, digital twin engines, Loiley X69 hardware, hackathon rules, the turbodrone codebase, and follow-control design.
- `critique.md`: gaps, contradictions between topics and which side the evidence favors, top risks, decisions the plan must make, and consolidated questions.
- `turbodrone-brief.md`: verified facts about turbodrone (commit 2c09cf8) and the X69 wire protocol.

Where a fact-checker corrected a researcher, the correction wins.
